## CSC102 Final Web Project

# Overview

This repository contains my coursework and final web project for CSC102: Introduction to Computer Programming at the University of Advancing Technology.

The site brings together the projects and programming concepts I worked on throughout the course, including HTML structure, CSS styling, JavaScript interaction, input validation, loops, arrays, classes, objects, sound, and event-driven programming.

Project Features

# Home Page

* Splash screen with an Enter Site button
* Final project introduction
* Site-wide navigation
* Animated Naruto meme image
* Start and Stop controls for image movement
* JavaScript-based movement and boundary detection

# Boards Page

* About Me section
* Advancing Computer Science degree objectives
* Contact information

# Game Page

* JavaScript-powered interaction
* Dynamic heading updates using innerHTML
* Arcade sound effect
* Event-driven button functionality

# Secret Message Page

* Menu for selecting between the Palindrome Checker and Secret Message
* User input validation
* First and last name validation
* ZIP code validation
* Secret message unlocked after successful validation
* Dynamic messages using innerHTML

# Palindrome Checker

* String manipulation using lowercase conversion and space removal
* Loop-based string reversal
* Decision logic using if/else
* Attempt counter
* Array collection of confirmed palindromes
* PalindromeCheck class and object
* Dynamic palindrome results using innerHTML

# Project Progress Table

* Displays completed CSC102 projects
* Lists the programming concept demonstrated by each project
* Shows completion status
* Styled using the shared external CSS file

# Programming Concepts Demonstrated

* Variables
* Functions
* Decision logic with if/else
* Loops
* String manipulation
* User input validation
* Arrays and collections
* Classes and objects
* Event-driven programming
* DOM manipulation
* Timers using setInterval() and clearInterval()
* Audio playback with JavaScript
* External CSS styling

# Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Git and GitHub

# How to Run

1. Clone this repository:

git clone https://github.com/TitaniumShinobi/csc102.git

2. Open the project folder.
3. Open index.html in a web browser.
4. Use the navigation menu to explore the project pages.

The site can also be viewed using the GitHub HTML Previewer.
