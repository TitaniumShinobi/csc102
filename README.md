# CSC102 Home Page

## Overview

This repository contains my coursework and web development projects for **CSC102: Introduction to Computer Programming**.

The project demonstrates fundamental HTML, CSS, and JavaScript concepts including:
- Creating structured webpages
- Styling webpages with CSS
- Using external fonts and layouts
- Adding interactive JavaScript elements

### Home Page
- Personal introduction
- About Me section
- Contact information
- Custom styling and layout

### Navigation
- Home page navigation
- Boards page navigation

### Game Page
